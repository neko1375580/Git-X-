# 📖 О проекте

Git X создаётся как полноценная платформа для ежедневной работы разработчиков.

Главная идея проекта — объединить десятки инструментов в одном месте.

Сегодня разработчику приходится одновременно использовать:

- GitHub
- VS Code
- Obsidian
- Notion
- Vercel
- Supabase
- ChatGPT
- Claude
- Gemini
- DevTools
- Markdown редакторы
- файловые менеджеры

Git X объединяет всё это в единую экосистему.

---

# ⚠️ Статус проекта

Git X находится в **активной разработке**.

Проект ещё нельзя считать завершённым.

Многие функции уже работают, однако архитектура постоянно развивается.

Каждый новый коммит делает платформу быстрее, удобнее и функциональнее.

---

# 🎯 Основная цель

Создать современную платформу, в которой разработчик сможет:

- писать код;
- управлять проектами;
- работать с GitHub;
- подключать Supabase;
- управлять деплоями;
- хранить файлы;
- создавать документацию;
- использовать AI;
- хранить API-ключи;
- вести заметки;
- работать со сниппетами;
- использовать встроенные DevTools.
